# flowpilot-core

FlowPilot runtime: graph validation, turn-scoped execution, bounded queues, cancellation and tracing.
Independent of Home Assistant; everything HA-specific lives in adapters.

Also here: the node registry, the built-in nodes First present (`text.first`), Text converter (`text.convert`) and Value (`logic.value`), and
the plugin conformance kit (`flowpilot_core.conformance`).
